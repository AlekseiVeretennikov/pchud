osifont-lgpl3fe.ttf — шрифт osifont (версия 0.1.20221020), https://github.com/hikikomori82/osifont
Чертёжный шрифт по ISO 3098, используется темой «Приборная панель».

Лицензия: GNU LGPL версии 3 с исключением для шрифтов (GPL font exception):
тексты LGPL-3.0.txt и GPL-3.0.txt рядом. Исключение означает, что документы и
программы, которые лишь используют шрифт (встраивают его, показывают им текст),
не обязаны распространяться под этой лицензией.

Изменения (2026-11-15, для PC HUD): в исходном файле вместо букв Ё ё Э э стоят
пустые прямоугольники. Ё и ё собраны из Е/е с двумя точками (как Ë/ë этого же
шрифта), Э и э — зеркальные отражения Є и є этого же шрифта. Остальное не тронуто.
Изменённый файл распространяется на тех же условиях (LGPL 3 с исключением для шрифтов).
